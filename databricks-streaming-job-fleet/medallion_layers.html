Compares 13 table counts and 2 revenue totals with the control totals.

Red if any layer disagrees, so a bug in Bronze (a4’s duplicates) still turns the fleet red even when Silver hides it.

Land
  • base CSVs → Delta tables
  • POS files → readStream, availableNow, one fixed checkpoint per stream
Clean and type
  • strings → int, decimal(5,2), timestamp (both POS formats)
  • de-duplicate by latest last_update
  • MERGE late returns into the open rental
  • join city/country, category
Keep history (SCD2)
  • rebuild from Bronze + every change file
  • fingerprint the tracked columns; keep a row only when it changes
  • valid_to = day before the next version
Roll up and tell
  • group by month and store
  • window rank within category and month
  • point-in-time join: rental date between valid_from and valid_to
Verify
  • every job’s CHECK cell vs the control totals
  • quality gate across all layers
